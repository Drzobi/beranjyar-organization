## 🎯 درباره پروژه

برنج‌یار یک پلتفرم جامع است که بازی، سرگرمی و خدمات کشاورزی را در یک تجربه واحد ادغام می‌کند. این پروژه از یک بازی ساده شروع شد و امروز به یک اکوسیستم کامل تبدیل شده است.

### ✨ امکانات اصلی

- 🎮 **بازی‌ها**
  - بازی مترسک (دفع پرنده با تکان دادن مترسک)
  - بازی شالیزار (جمع‌آوری برنج یار کوین)

- 🛠️ **خدمات کشاورزی**
  - 🔍 تشخیص آفت با هوش مصنوعی (Gemini)
  - 📅 تقویم کشاورزی هوشمند
  - 🛒 بازارچه برنج
  - 💡 مشاور کشاورزی AI

- 💰 **سیستم توکن**
  - BYC (BeranjYar Coin) - توکن واحد
  - کسب از طریق بازی‌ها و فعالیت‌ها
  - استفاده در بازارچه و خدمات

- 📱 **دسترسی چندپلتفرمی**
  - وب (مرورگر)
  - PWA (نصب روی موبایل)
  - APK اندروید
  - ربات تلگرام
